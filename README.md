# 🕹️ **The Game Awards 2023 — Themed Website**

**The Game Awards 2023** is a themed website developed using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**, designed to capture the essence and visual identity of the annual *Game Awards* event.  
The project focuses on delivering an immersive user experience through modern design, responsive layouts, and interactive elements.

---

## 🌐 **Overview**

The website recreates the atmosphere of *The Game Awards 2023*, featuring multiple sections that highlight nominees, event information, and the Game of the Year winner — all presented within a clean and visually consistent interface.

---

## ✨ **Main Features**

- ⏳ **Custom Loading Screen:** Inspired by *The Game Awards* branding and visual identity.  
- 📰 **Event Information Page:** Includes general details about the ceremony and its history.  
- 🔐 **Login Screen:** Prepared for future user registration and authentication.  
- 🏆 **Nominee Section:** Displays all award categories and their respective nominees.  
- 🎮 **Winner Page:** Dedicated page announcing the **Game of the Year**.  
- 📱 **Responsive Design:** Ensures smooth viewing across all devices.  

---

## ⚙️ **Technologies Used**

- 🧱 **HTML5** – structure and content layout  
- 🎨 **CSS3** – styling and theming  
- ⚙️ **JavaScript** – interactivity and dynamic content  
- 🧩 **Bootstrap** – responsive grid and UI components
