## 📖 About

A fan-made, academic recreation of **The Game Awards 2023** website, developed as a group project for an IT course at ISTEC Lisbon. It captures the event's visual identity across several pages: nominees by category, winners, past editions, the ceremony video and more. It uses a responsive Bootstrap layout and a little JavaScript for interactivity.

## ✨ Pages & Features

| Page | Description |
|------|-------------|
| `loading.html` | ⏳ Custom animated loading screen inspired by the event's branding |
| `index.html` | 🏠 Home page with event highlights |
| `categorias*.html` / `cat.html` | 🏆 Award categories and nominees, split across several pages |
| `vencedores.html` | 🎮 Winners, including **Game of the Year** |
| `eventos_passados.html` | 📅 Past editions of the ceremony |
| `video.html` | 🎬 Ceremony video page |
| `sobre1.html` | 📰 About the event and its history |
| `pagina_login.html` | 🔐 Login screen (front-end only) |

- 📱 **Responsive design** through the Bootstrap grid
- 🎨 Custom stylesheets with a dark, orange-accented look inspired by the event

## 🚀 Getting Started

No build step is needed: it's a static website.

```bash
git clone https://github.com/DiasDias106/The-Game-Awards-2023-Themed-Website.git
cd The-Game-Awards-2023-Themed-Website/The_game_awards_costume_website/trabalho_grupo_ti_final
```

Then open `loading.html` (or `index.html`) in your browser, or serve the folder with any static server:

```bash
python -m http.server 8000
# open http://localhost:8000/loading.html
```
